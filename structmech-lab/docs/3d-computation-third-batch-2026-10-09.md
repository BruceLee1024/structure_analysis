# 三维计算第三批实施与验证

日期：2026-10-09（北京时间）

本批完成 PCG 原始系统收敛修正，以及空间页面的多工况/组合批量计算与包络来源追踪。仍限于当前空间杆系线弹性静力模型；没有宣布整个优化计划或阶段 A 全部完成。未提交、推送或部署。

## 计算修改

对称缩放采用 `A_s = S A S`、`b_s = S b`、`x = S y`。原有迭代用缩放残差决定停止，而最后才检查原始 `b-Ax`；两个尺度的容差并不等价，导致大型基准经常提前停止并降级到 dense。

现在按 `||S⁻¹ r_s|| / ||b||` 判断迭代进展，在候选收敛点重新计算原始 `b-Ax`。递推残差与真实残差不一致时，从真实残差重启方向，继续使用同一迭代预算；未放宽原始系统验收容差。最终再次检查真实残差。诊断开启与关闭使用同一计算逻辑。

同时取消 `pᵀAp <= 1e-30` 的固定曲率阈值，只把非正曲率或非有限值判为失败，避免微小荷载被误判为奇异；非有限残差仍会停止。回归测试覆盖缩放先达标后继续迭代、预算不足仍失败、1e-18 量级荷载和 1080 自由度关闭降级求解。

研究依据：PETSc 区分预条件残差与真实残差，并说明直接重算真实残差有额外成本。本实现只在候选收敛点重算，另保留最终验证。[PETSc KSP 手册](https://petsc.org/release/manual/ksp/)

## 批量计算与界面

- “计算全部工况与组合”在同一 Worker 会话内求解；工况荷载、组合系数、自重和对应警告沿用模型层规则。同步降级路径提供同样的批量结果。
- 下拉框切换已计算目标，位移、反力、杆内结果和视口同步切换；切换与点击包络来源不发出新求解请求。
- 包络覆盖本批所有有效结果。来源链接打开对应工况/组合，并选中对应杆件或节点；已有轴力、剪力、弯矩显示会随相应行切换。扭矩来源只定位，未引入新的扭矩图层。
- 失败目标排除出包络，并显示“不完整包络”提示；目标选择器保留失败项，允许检查后切换到有效目标。警告项保留“需检查”状态，空工况提示不会被隐藏。
- 节点、截面、荷载、组合系数或自重改变会使整批结果过期，暂停显示结果表、包络及变形。仅切换编辑/查看工况不会使已计算批次过期。
- 旧请求替换或卸载仍用 terminate 停止在途 Worker，过期响应不能覆盖新请求；硬取消会丢失该 Worker 的缓存。本批没有新增显式取消按钮或迭代让出机制。

批量诊断中的 `stiffnessAssemblies` 表示本批新装配次数；`matrixDiagnosticsBuilds / denseFactorizations / preconditionerBuilds` 表示当前结构上下文的累计准备次数。跨请求保持缓存时，前者可为 0，后者仍为 1；结构改变后上下文计数重新开始。

## 性能测量

与上一批相同的 Apple M4、Node v26.7.0、auto 后端和 1e-8 容差；20 个比例变化工况，每组 2 次预热、12 次样本，含首次结构准备、数值求解与后处理。最终测量在测试、构建及浏览器检查结束后单独运行。以下为上一批缓存版与本批的对比。

| 模型 / 自由度 | 上一批 median / P95 ms | 本批 median / P95 ms | 本批实际后端 |
|---|---:|---:|---|
| 小 / 24 | 2.28 / 2.67 | 2.67 / 3.61 | dense-reference |
| 中 / 288 | 34.21 / 40.61 | 38.79 / 49.36 | dense-reference |
| 大 / 1080 | 287.46 / 305.50 | 126.14 / 152.63 | js-csr-pcg |

大型模型冷准备 20 次的中位耗时另由 3137.06 ms 降至 473.29 ms。复用路径最大真实相对残差 5.7922e-9，满足 1e-8 容差。

大型模型上一批实际为 PCG → dense 回退，本批实际为 PCG，未改变请求容差。这是避免不必要回退后的实测收益，不能外推为所有矩阵的 PCG 提速；小、中模型仍走 dense，本批未得到一致性能收益。
