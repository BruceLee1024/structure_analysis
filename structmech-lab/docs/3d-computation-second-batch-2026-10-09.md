# 三维计算优化：独立复算与上下文复用

日期：2026-10-09（北京时间）\
状态：第二批完成；A1 已补一组独立算例与 Node 基线，B1 已接入重复求解路径；原计划整体尚未验收

## 本批行为

- 新增 9 个可保存、可重算的空间模型，使用 PyniteFEA 3.2.0 独立生成参考结果。
- 同一结构只改荷载时复用刚度、矩阵诊断、刚体约束诊断、dense 分解或 PCG 缩放/对角数据。每个右端仍独立求解，并复核原始系统真实残差。
- Worker 与同步降级使用同一会话机制；当前工况页面反复计算、换荷载，以及已有批量工况工具都能使用复用路径。
- 准备上下文拥有节点、支座、弹簧、截面及释放的输入快照；修改调用方对象不会造成“新模型、旧矩阵”混用。
- 按完整结构字段生成键：节点编号/次序/坐标/约束/弹簧，杆件编号/次序/连接/E/A/Iy/Iz/J/ν/roll/两端释放。结构变化重建；荷载、容差、迭代上限独立处理。改变预条件器或诊断模式仅准备所需数据。
- 每个会话保留一个结构上下文；dense 仅保留最近一个有效自由度分区，PCG 按三个预条件模式保存准备数据，诊断按 basic/extended 保存。释放无刚度转角从无荷载变为受荷载时，不复用旧的 reduced dense 分解。
- 统计显示缓存命中及累计诊断/分解/预条件准备次数；统计限定于当前结构上下文。后续工况的 assemblyMs 不再重复计入之前已完成的刚度装配耗时。
- 保留原有请求编号、过期结果丢弃和在途 Worker terminate 取消机制；硬取消会丢失该 Worker 缓存。

## 独立验证

9 个模型：混合节点力/力矩悬臂、局部 y / z 均布、37° roll 非对称截面全局梯形荷载、简支三角荷载、固支端释放、弹簧端支承、斜杆、空间门架。

输入显式给出目标局部 y，参考适配器从 Pynite 默认局部轴求 rotation；不假定默认轴与应用相同。参考程序不导入应用求解器。方法及 API 依据：[Pynite 构件坐标](https://pynite.readthedocs.io/en/latest/member.html)、[FEModel3D](https://pynite.readthedocs.io/en/latest/FEModel3D.html)。

两条后端路径共 **18/18 通过**，包括已准备上下文重复求解。对比节点平移/转角、反力、杆端力及 5 个杆内位置位移。相对容差 1e-7，平移绝对容差 1e-6mm、转角 1e-9rad、力/矩分别 1e-6kN / 1e-6kN·m、杆内位移 1e-9m。

| 最大绝对误差 | 实测 |
|---|---:|
| 节点平移 | 5.56e-13 mm |
| 节点转角 | 1.04e-16 rad |
| 支座力 | 3.13e-11 kN |
| 支座力矩 | 4.37e-11 kN·m |
| 杆端力 | 5.06e-10 kN |
| 杆端力矩 | 5.03e-11 kN·m |
| 杆内位移 | 5.65e-16 m |

这些误差只代表保存的线弹性算例覆盖，不能外推到尚未验证的机构、非线性、板壳、动力或规范验算。

参考输入/输出位于 `tests/fixtures/space/`；[复算步骤](../scripts/space/README.md)，[逐算例误差与容差](./benchmarks/space-reference-comparison-2026-10-09.json)。Pynite、NumPy、SciPy 固定版本保存在 `scripts/space/requirements-reference.txt`；本批仅安装在临时独立 Python 环境，未新增应用依赖。

## 性能前后测量

设备 Apple M4，macOS arm64，Node v26.7.0。相同参数、auto 后端、tolerance=1e-8、允许原有 dense 回退。每组 20 个比例变化荷载，2 次预热、12 次测量；每次测量包含首次结构准备及 20 次完整数值计算与后处理。

以下比较的是优化前已有“共用装配”路径与优化后进一步复用分解/预条件准备的同一路径。

| 模型 | 节点 / 杆件 / 自由 DOF | 前 median / P95 ms | 后 median / P95 ms | median 比值 |
|---|---|---:|---:|---:|
| 小 | 8 / 10 / 24 | 3.16 / 3.61 | 2.28 / 2.67 | 1.39× |
| 中 | 64 / 138 / 288 | 89.35 / 96.12 | 34.21 / 40.61 | 2.61× |
| 大 | 216 / 530 / 1080 | 2940.55 / 3069.02 | 287.46 / 305.50 | 10.23× |

**大型样例实际执行了 PCG→dense 成功回退。** PCG 缩放残差达到其门槛后，原始系统真实残差未达门槛，按已有规则回退；本批复用了回退分解，未降低正确性门槛。大样例的 10.23× 主要来自避免重复 dense 分解，不能解释为通用 PCG 提速。

缓存计数：20 个右端只有一次刚度装配、一次矩阵诊断、一次 dense 分解；大型样例另有一次 PCG 准备。原始样本及源码 SHA256 见 [优化前](./benchmarks/space-before-context-cache-2026-10-09.json)、[优化后](./benchmarks/space-after-context-cache-2026-10-09.json)。单次冷求解没有得到一致显著收益：小型约相当，中型略有波动，大型有所下降；本批收益定位于重复求解。

测量不包括浏览器 Worker 通信、GPU/FPS、峰值内存；未归档优化前完整的脏工作区源码，仅记录了指纹与原始样本。脚本和模型生成参数可用于后续同条件测量。
