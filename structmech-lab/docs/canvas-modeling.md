# 画布直接建模

进入结构求解器的“建模”工作区，使用画布顶部的绘图工具。支座和荷载从“放支座”“加荷载”分类菜单选择。可以继续编辑已有模型，也可以点击“新建空白模型”开始；新建、删除和属性修改均可通过画布撤销恢复。完成绘图后的模型沿用原来的求解、工况组合、保存和报告流程。

## 绘制截图中的悬臂梁

1. 新建空白模型，选择“画杆件”。
2. 输入长度 `4` m，方向选择“水平”，点击画布起点，再点击“完成杆件”。按 Esc 结束连续绘制。
3. 点击“适应模型”，选择“固定支座”，点击梁左端。
4. 选择“均布荷载”，大小填 `-3` kN/m，沿梁从左端拖到中点。也可选中荷载，在属性面板把起点设为 `0`、终点设为 `2` m。
5. 选择“集中力”，大小填 `-2` kN，点击右端。
6. 结果自动更新：竖向反力 `8` kN、固定端反力矩 `14` kN·m。

## 常用操作

- 杆件支持两次点击或按住拖动绘制；勾选连续绘制后，终点作为下一根的起点。Esc 结束当前连续绘制。
- 吸附开启时，端点吸附到已有节点、杆件和所选网格。输入精确长度优先于网格。用“水平 / 竖直”约束方向。
- 新绘制杆件的交点及杆件中间新增节点自动连接、打断杆件，并重新分配原荷载；新杆件使用当前截面属性。普通交点为刚接，端部铰接可在杆件属性中设置。
- 支座可放在已有节点或杆件上。竖向滚动支座约束 Y 位移，水平滚动支座约束 X 位移。
- 均布和梯形荷载沿同一单元拖动确定范围。逆向拖动梯形荷载时，起终大小随拖动方向映射。拆分后的多根杆件可分别放置荷载。
- 集中力和力矩可放在节点或单元内部。力的正值向上 / 向右，力矩的正值逆时针。
- “选择 / 移动”可选中节点、杆件及荷载箭头。属性修改后点击“应用修改”；修改杆长沿原方向移动终点及相连杆件。
- 节点删除同时删除相连杆件与所有工况的关联荷载；杆件删除同时删除其关联荷载。可撤销恢复。
- 画布使用固定视口，绘制不会自动缩放。“平移画布”、放大、缩小和“适应模型”只改变视图。
- 画布取得焦点时，Delete 删除选中对象，Ctrl / ⌘ Z 撤销，Ctrl Y / ⌘ Shift Z 重做。输入框中的按键保留正常文字编辑功能。
- 画布最多保留 50 步撤销。参数面板、文件加载或 AI 修改模型后清空画布历史，避免恢复旧快照覆盖新工作。
- 画布编辑的荷载属于工具标题标明的编辑工况；计算结果仍遵循当前分析目标。构造尚未完成或支座不足时，模型校验和求解诊断会提示问题。

## 工作区布局

- “建模”专注画布，选中对象后显示属性栏；“内力图”集中查看四张结果图；“结果表”查看反力、内力、位移、包络与平衡校验。切换工作区保留绘图状态和撤销历史。
- 顶部切换计算工况，保存、加载模型与导出报告。组合结果与画布编辑工况分别标示。
- “模型配置”按模型、荷载、工况、显示、校验分类，结构模板、截面库和节点表均保留。配置面板与结构助手按需展开；窄窗口使用可关闭的浮动面板。
- 顶部“计算检查”展开诊断和控制位置，点击定位可直接转到内力图。
